# Medical-Training Lineage Comparison

Paired 40-patient frontal-CXR comparison between HuatuoGPT-Vision-7B and its
exact-size Qwen2.5-VL-7B base architecture.

The confirmatory training-lineage condition failed: the medical-minus-base
style variance fraction was \(+1.22\) percentage points with paired bootstrap
95% interval \([-0.98,+3.63]\) points.

The normalized style susceptibility was lower after medical training:
\(-0.101\), 95% interval \([-0.145,-0.027]\). This supports medical style
contraction under the tested source operator, not training-induced
style-conditioned prior switching.
