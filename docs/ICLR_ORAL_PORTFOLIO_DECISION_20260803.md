### 2.1 Specificity Ratchet — current substrate closed; future problem only

**Paper type:** New Problem/Setting.

**One-sentence story:** Medical VLMs may cross during spontaneous generation
from a visually supported clinical parent to an unsupported descendant
constraint; the missing correction is a one-for-one return to the nearest
supported ancestor, not deletion or hedging.

**Why the abstract problem retains a high ceiling.** The basic unit is clinically meaningful and
different from a flat fabricated entity. It yields a visible state transition,
a separating image-swap prediction, and a content-preserving intervention.
The closest-work audit leaves this narrow output-side causal estimand open,
whereas generic fine-grained hallucination, query granularity, region grounding
and span editing are occupied.

**Why the current execution is closed.** Of 127 proposed edges, 76 create the
parent by deletion/substitution rather than observing it before the constraint.
Only 24 edges (22 cases) expose a strict sentence-closed parent first; they are
limited to etiology/subtype, with 8 dev and 14 test cases and zero repeated
constraint blocks per split. This fails the frozen prevalence and edge-type
gates before physician outcomes. A future substrate must collect natural
parent-before-constraint image-grounded outputs or validate an independent
held-out parent-identity readout; the present pack cannot authorize a canary.

**Paradigm-shift probe:** First Principles = yes (clinical claims are a support
hierarchy, not flat entities); Elephant in the Room = yes (deletion can hide
hallucination by destroying supported content); Technology Cycle = partial
(full-answer token traces and causal VLM replay are now practical); Hamming =
yes if replicated. Disruptive potential is strong but entirely conditional.

### 2.2 CECD — operational priority 1

**Paper type:** New Setting.

**One-sentence story:** If two independently admitted transformations preserve
the clinical proposition and evidence, their centered cross-modal interaction
should be zero; a replicated nonzero mixed derivative is a composition defect,
not ordinary prompt or render sensitivity.

**Why it remains alive.** PSF-Med occupies the language-equivalence axis and
Visibility Benchmark occupies the visual×text factorial shape, but neither
tests two meaning-preserving clinical nuisance operations with a reader-grounded
centered interaction. This is a real remaining delta, although narrower than
the original proposal.

**Method boundary.** Equivalence-curvature cancellation is a classical ANOVA
projection and collides with generic activation/concept-subspace steering. It
may be used only as an interaction-component ablation, with full-orbit,
marginal-average, random/sign-permuted, main-effect and faithful Treble controls.
If orbit averaging matches it, there is no CECD-specific mitigation result.

Treble's public proceedings and released source disagree, so “faithful Treble”
cannot mean silently selecting one. Exact paper-native reproduction remains
blocked. If Stage 1 passes, the only authorized fallback is the pre-frozen
dual-semantics common-protocol envelope: CECD must beat both independently
implemented source variants and full-orbit averaging in both models under the
same no-exchange clinical contract. This repairs experiment sequencing but
does not turn either variant into an exact baseline.

**Two major flaws before execution.** Four role-isolated human returns are
absent, so neither image nor language equivalence is admitted. Even if they
pass, a significant interaction alone is insufficient: the effect must add
held-out clinical-error information in Huatuo and Hulu and support a causal
explanation beyond both main effects.

**Paradigm-shift probe:** First Principles = yes (equivalences should compose);
Elephant = partial; Technology Cycle = no; Hamming = partial. This is a clean
mechanism section or main-track candidate if replicated, but its current oral
ceiling is below Specificity.

### 2.3 Unified physician OE/mitigation audit — supporting module

The 24-group/101-answer-unit role-isolated review can determine whether an
apparent mitigation gain is fabrication reduction or merely shorter output,
omission, refusal, hedging, or lost usefulness. This solves a serious evidence
problem and is required for either surviving paper. It is not a new neural
mechanism, so presenting it alone as the ICLR contribution would fail novelty
and claim-verifiability gates.

## 5. Oral claim ceiling

An oral-level submission is authorized only if one surviving pivot supplies all
of the following in the same causal story:

1. independent clinical construct truth;
2. a held-out, cross-family state transition or non-separable mechanism;
3. a separating causal intervention with strong null controls;
4. improved physician-grounded OE/report fidelity at matched claim count and
   coverage, with omission, refusal, hedging and length reported;
5. a closest-work delta that survives the existing 2025–2026 collision audit;
6. provenance-complete figures, tables, statistics and reproducible code.

At present, none of these six is fully satisfied. This document freezes the
path to obtaining them; it does not lower the bar.
