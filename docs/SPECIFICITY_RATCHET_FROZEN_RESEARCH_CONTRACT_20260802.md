## 1. Frozen problem

The paper question is:

> During open-ended medical generation, does a model spontaneously move from a
> visually supported parent claim to an unsupported descendant constraint, even
> though the parent remains available?

The unit is one physician-admitted adjacent edge `parent -> child`, not a whole
answer, token keyword, or automatically extracted entity. The claim is bounded
to image-grounded clinical constraints such as laterality, size/morphology and
subtype. Etiology or missing-history claims form a separate evidence-source
boundary and never enter the primary visual endpoint.

This problem survives the completed negative screens because it is not:

- reader-clarity erasure, which the frozen two-plane experiment rejected;
- a prompt-injected fine-grained negative query, already covered by FINER;
- generic template collapse or prompt copying;
- cross-answer-space inconsistency, for which the local exact-pair substrate
  fails F6/F7 and the broad mechanism collides with prior work;
- a shorter-answer or deleted-claim route to lower hallucination.

## 3. Frozen candidate mechanism

### Causal variable

The added-constraint commitment relative to matched non-constraint tokens in
the model's own complete visible OE answer. Parent support defines the clinical
group; an automatically shortened parent string is never a model input.

### Causal chain

1. The image supports a coarse parent finding.
2. Generating the parent activates language-trained descendant continuations.
3. For a supported child, image and lexical continuation agree.
4. For a parent-only case, the lexical descendant prior grows without matching
   constraint evidence and can cross the child decision boundary late.
5. The model therefore over-specifies instead of remaining at the nearest
   supported ancestor.

This is an unconfirmed mechanism. Final unsupported detail alone is not
evidence for a ratchet.

### Unique prediction

At the same physician-admitted edge, supported-child and parent-only cases must
already differ in image-specific constraint evidence before the late crossing.
Only parent-only cases should acquire a positive late-minus-early constraint
shift relative to matched non-constraint tokens despite lacking a corresponding
own-image-versus-swapped-image residual. Token count, prompt request and answer
length are controlled; text-only is a secondary lexical sensitivity analysis.
In addition, a parent-identity state must be observed before the constraint and
must remain stable across the putative crossing. The child event is therefore
an interaction (`parent retained` AND `constraint reverses`), not a positive
slope in modifier logits.

### Simple alternatives

- static perceptual error: the child is already preferred at the first
  image-integrating layer;
- lexical frequency: the same shift occurs text-only and is explained by NLL;
- position/template geometry: own-image and matched swapped-image residuals do
  not separate despite identical visual-token length;
- answer length: random matched additions show the same pattern;
- prompt compliance: the effect is confined to questions explicitly requesting
  the added constraint;
- parser granularity: physicians do not agree that the child entails the parent
  plus one constraint.

### Separating intervention

At the frozen crossing stage, patch the parent-supported residual or project
only the added-constraint component toward the nearest supported ancestor,
restoring activation norm. A valid intervention must suppress unsupported
children while preserving matched supported children, parent identity,
polarity, claim count and response length.

### Falsification

Kill the mechanism if any of the following holds:

1. two physicians cannot stably admit the edge/support/source states;
2. errors are mostly fabricated parents rather than parent-only descendants;
3. the error/control late-minus-early contrast has a case-cluster bootstrap CI
   including zero after frozen nuisance controls;
4. random swaps, text-only, length-matched or prompt-request controls reproduce it;
5. selective patching harms supported children or parent retention by more than
   one percentage point;
6. fewer than two model families and three edge types replicate;
7. mitigation gains disappear at fixed claim count and matched coverage.
8. no directly observable or held-out-validated parent state exists before the
   added constraint, or parent identity falls together with the constraint.

## 6. Paper-construction analysis

These are analytical reconstructions of exemplar papers, not claims about the
authors' private discovery histories.

- **Model Collapse:** turn a broad failure into a state transition. Here the
  relevant transition is the parent-to-child crossing, not the final error
  count. This is the strongest influence.
- **SigLIP:** remove accidental coupling at the objective level. The method must
  bound only the unsupported added constraint rather than couple hallucination
  reduction to fewer claims or a globally shorter answer.
- **ViT:** redefine the basic unit. The useful unit is a physician-admitted
  ontology edge with a support boundary, not a report sentence or keyword.
- **Transformer:** promote the mechanism-carrying primitive. If the edge-level
  crossing is real, nearest-supported-ancestor projection becomes the decoding
  primitive instead of a post-hoc report deletion rule.

The user's problem-first, mechanism-first preference mutes the Chinchilla-style
scaling path and prioritizes Model-Collapse dynamics plus SigLIP-style
decoupling.

## 8. First real-path probe after admission

- **Input:** the smallest image-disjoint admitted dev split with both
  `supported_specificity_control` and `causal_escalation_error` roles.
- **Identity gate:** deterministically regenerate one admitted Huatuo case as
  an engineering canary, then capture every selected case. Require direct raw
  generation IDs, decoded-text identity, contextual-target-ID identity and
  equal own/swap visual-token counts before any mechanism score is interpreted.
- **Baseline:** replay the model's complete natural visible OE answer; never
  score an isolated automatically shortened parent or child proposal.
- **Intervention:** none in the screen. Trace the complete answer with its own
  image and at least two frozen, different-case modality/anatomy-matched image
  swaps of identical visual-token length. Text-only is secondary.
- **Observable:** error-versus-control late-minus-early change in added-
  constraint commitment relative to same-answer matched non-constraint tokens,
  jointly with the own-image-minus-swap difference-in-differences.
- **Work condition:** child supported.
- **Non-work condition:** parent supported, child refuted/undetermined.
- **Positive outcome:** on both frozen splits, error cases have weaker early
  image-specific evidence and a nuisance-adjusted late constraint commitment
  gain that survives both image swaps; the lower case-bootstrap bound for the
  swap-surviving fraction must exceed 0.50.
- **Negative outcome:** static perception, lexical frequency or parser
  granularity explains the final detail; kill the ratchet claim.
- **Artifact:** frozen manifest, atomic layer traces and case-cluster bootstrap
  analysis.
- **Budget:** CPU compile first; then one Huatuo canary and at most 2--4 GPU
  hours for the first screen. No second model or mitigation before this signal.

## 9. Method ceiling

Only after the mechanism passes may the project implement fixed-K
nearest-supported-ancestor projection:

\[
K_{after}=K_{before},\qquad \Delta K=0.
\]

It replaces one unsupported descendant with its supported ancestor. It may not
delete a claim, add a blanket hedge, refuse the answer, insert an ontology claim
that was not generated, or reduce the positive-claim count. The first screen
can earn only a bounded mechanism result; it cannot yet earn an OE mitigation
or general medical-hallucination claim.
